# Observability Demo

Preserve trace, correlation, and request identifiers on every tool call.

Report dependency failures clearly. Include tool names, step numbers, workflow id, fault mode, and outcomes in structured logs.

Do not include raw credentials, tokens, or full dependency payloads in logs.
