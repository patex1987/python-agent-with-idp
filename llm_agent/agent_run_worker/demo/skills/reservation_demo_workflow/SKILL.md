# Reservation Demo Workflow

Prefer the recommended movie. Pick the first available screening and the first available seat for that screening.

Request the reservation, poll the reservation request status, then fetch the reservation result.

Stop when the reservation is confirmed, rejected, failed, or the workflow reaches its maximum step count.
